# Data Dictionary

This document provides the authoritative schema, data types, nullability rules, and domain definitions for all raw and processed data artifacts in the `data/` directory.

---

## 1. Raw Telemetry Artifact (`data/raw/`)

### `IOT-temp.csv`
The raw, unmodified sensor transaction log downloaded from Kaggle (`atulanandjha/temperature-readings-iot-devices`).
- **Row Count:** 97,606 rows (contains 1 duplicate).

| Column Name | Data Type | Nullable | Example Value | Description |
| :--- | :--- | :--- | :--- | :--- |
| `id` | String | No | `__export_xyz_123` | Transaction hash identifier generated by export tool. |
| `room_id/id` | String | No | `Room Admin` | Deployment location identifier (100% constant invariant). |
| `noted_date` | String | No | `08-12-2018 09:30` | Telemetry timestamp formatted as `DD-MM-YYYY HH:MM`. |
| `temp` | Integer | No | `38` | Integer temperature reading recorded by the sensor (°C). |
| `out/in` | String | No | `'Out'`, `'In'` | Categorical channel tag: `'Out'` (external) or `'In'` (internal). |

---

## 2. Preprocessed Clean Reference Artifacts (`data/processed/`)

### `out_features.csv` & `in_features.csv`
Clean, deduplicated time-series feature tables generated by `src/preprocessing.py`. These files are immutable ground-truth references and contain **no synthetic anomalies**.
- **Row Counts:** `out_features.csv` = 77,299 rows; `in_features.csv` = 20,306 rows.

| Column Name | Data Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `id` | String | No | Inherited transaction identifier. |
| `room_id/id` | String | No | Location tag (`Room Admin`). |
| `noted_date` | String | No | Original raw timestamp string. |
| `temp` | Float64 | No | Unperturbed temperature observation (°C). |
| `out/in` | String | No | Channel category (`Out` or `In`). |
| `ts` | Datetime64[ns] | No | Parsed ISO timestamp (`dayfirst=True`, chronological order). |
| `gap_seconds` | Float64 | Yes (Index 0) | Seconds elapsed since previous observation within this series. |
| `rolling_mean` | Float64 | No | Trailing 10-reading mean of `temp` (`min_periods=1`). |
| `rolling_std` | Float64 | Yes (Index 0) | Trailing 10-reading standard deviation of `temp` (`min_periods=2`). |
| `in_out_diff` | Float64 | Yes (Gaps > 15m) | Nearest cross-channel temperature difference ($T_{\text{target}} - T_{\text{other}}$). |

## 3. Labeled Anomaly Artifacts (`data/processed/`)

### `out_labeled.csv` & `in_labeled.csv`
Telemetry tables generated by `src/anomaly_injection.py` containing synthetic anomaly injections alongside unperturbed historical readings.

| Column Name | Data Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| *(All Feature Columns)* | *(Inherited)* | *(Inherited)* | Preprocessing columns preserved as unperturbed baselines. |
| `temp_injected` | Float64 | No | Temperature signal incorporating synthetic perturbations (°C). |
| `is_injected_anomaly`| Boolean | No | Ground-truth binary flag: `True` if row falls inside an injection window. |
| `injection_type` | String | Yes | Typology label: `'step'`, `'drift'`, `'flatline'`, or `None`. |

### `injection_log.csv`
Audit log recording every injected perturbation parameters (30 rows total).

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `injection_id` | String | Unique injection identifier (e.g., `out_step_000`, `in_drift_016`). |
| `series` | String | Sensor channel (`Out` or `In`). |
| `type` | String | Fault typology (`step`, `drift`, `flatline`). |
| `start_idx` | Int64 | Positional integer start index in series DataFrame. |
| `end_idx` | Int64 | Positional integer end index (inclusive). |
| `start_timestamp`| String | ISO timestamp corresponding to `start_idx`. |
| `duration` | Int64 | Number of consecutive readings perturbed ($D \in [5, 30]$). |
| `magnitude` | Float64 | Additive magnitude for step injections (NaN for flatline/drift start). |
| `final_magnitude`| Float64 | Peak additive offset for drift injections (NaN for step/flatline). |
| `frozen_at` | Float64 | Temperature value frozen during flatline injections (NaN for others). |
| `seed` | Int64 | Master pseudo-random seed (`42`). |

### `injection_train_test_status.csv`
Extends `injection_log.csv` with chronological partition status:
- `train_test_status`: String (`'train'` if injection occurred before `2018-10-29 11:10:48`; `'test'` if completely after).

## 4. Model Scoring & Evaluation Artifacts (`data/processed/`)

### `if_scores_out.csv` & `if_scores_in.csv`
Telemetry stream enriched with continuous Isolation Forest anomaly scores.

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `rolling_mean_if` | Float64 | Trailing 10-reading mean recomputed from `temp_injected` (D5/D22). |
| `rolling_std_if` | Float64 | Trailing 10-reading standard deviation recomputed from `temp_injected`. |
| `if_score` | Float64 | Continuous decision function score (negative indicates anomaly). |
| `if_anomaly_flag` | Boolean | Discrete detection flag (`True` if `if_score < 0.0`). |

### `three_way_comparison.csv`
The master comparative early warning scorecard across all 30 injections.

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `injection_id` | String | Unique injection key. |
| `series` | String | Channel (`Out` or `In`). |
| `type` | String | Fault type (`step`, `drift`, `flatline`). |
| `train_test_status` | String | Partition label (`test` or `train`). |
| `baseline_lead_time_min` | Float64 | Runway from baseline alarm to irreversibility (minutes). |
| `lead_time_IF_min` | Float64 | Runway from Isolation Forest alarm to irreversibility (minutes). |
| `lead_time_LSTM_min` | Float64 | Runway from LSTM-Autoencoder alarm to irreversibility (minutes). |
| `delta_lead_time_IF_min` | Float64 | Additional runway gained by IF over Baseline (`lead_time_IF - baseline_lead_time`). |
| `delta_lead_time_LSTM_min`| Float64 | Additional runway gained by LSTM over Baseline. |
| `lstm_evaluation_reason` | String | Evaluation qualification (e.g., `Evaluated`, `No baseline alarm`, `Blind spot`). |

### `twin_crosscheck_report.csv`
Audit verifying mathematical parity between offline batch detectors and online digital twin monitors (90 rows: 30 injections $\times$ 3 detectors).

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `injection_id` | String | Injection key. |
| `detector` | String | Monitor type (`baseline`, `isolation_forest`, `lstm_autoencoder`). |
| `batch_alarm_ts` | String | Alarm timestamp generated by batch evaluation pipeline. |
| `twin_alarm_ts` | String | Alarm timestamp generated by SimPy streaming monitor. |
| `match` | String | Parity status: `'True'`, `'False'`, or `'not_applicable'` (train demo). |
| `discrepancy_seconds` | Float64 | Temporal drift between batch and twin alarm (verified: 0.0 s). |
| `notes` | String | Diagnostic context or pre-warming verification details. |
